# Provedown Documentation

Provedown is a markdown-native framework for verifiable literate documents. The
human-readable document remains the primary artifact, while embedded assertions
can be checked by independent verifier plugins.

This documentation is organized with the Diataxis structure:

- **Tutorials** teach new workflows step by step.
- **How-to guides** solve focused operational tasks.
- **Reference** describes stable APIs, commands, and file formats.
- **Explanations** discuss design choices and tradeoffs.

The project is still early, so examples and reference pages describe what exists
today while the design notes track where the format is heading.
